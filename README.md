# gadagada

Software Project

## **一、项目背景**

高校实验室安全隐患多源于不规范操作，人工巡检效率低、排查不及时。本项目旨在开发一套辅助工具，提升安全检查效率。

## **二、项目目标**

在 40 学时内，完成一套实验室安全行为识别原型工具，实现：

· **功能**：识别不安全行为，生成风险报告

· **定位**：人工巡检辅助工具，不做人脸识别，不接入实时监控

## **三、核心业务与功能**

**业务流程**：上传照片 / 30秒以内视频 → AI 识别不安全行为 → 输出风险报告

**核心功能**：

1. 支持图片、30秒以内短视频上传

2. 识别护目镜、手套佩戴及防护服穿戴等违规行为

3. 自动生成安全风险报告

4. 保存并查询历史检测记录

5. 内置实验室安全规范知识库

## **五、方案可行性**

1. **应用价值**：解决真实实验室安全检查痛点

2. **隐私合规**：只识别行为，不识别个人身份

3. **工作量适配**：适合小组课程实训，技术难度可控

4. **风险可控**：AI 识别结果仅供参考，需人工复核
